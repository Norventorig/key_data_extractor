# Key Data Extractor

Приложение на Python для извлечения заданных параметров из неструктурированных документов с использованием мультимодальных LLM.

Программа принимает документ, извлекает из него текст, затем передаёт содержимое языковой модели и возвращает необходимые пользователю параметры в структурированном JSON-формате.

## Задача

В документах PDF, DOCX и изображениях важная информация часто хранится в неструктурированном виде.

При большом количестве документов ручной поиск нужных значений занимает много времени.

Цель проекта — автоматизировать процесс:

```text
Документ
   ↓
Извлечение содержимого
   ↓
LLM
   ↓
Поиск заданных параметров
   ↓
JSON
```

## Как работает приложение

Работа программы разделена на два основных этапа.

### 1. Извлечение содержимого документа

Логика находится в:

```text
retrieve_text.py
```

В зависимости от формата документа используется разный подход.

### PDF

PDF преобразуется в изображения отдельных страниц с помощью PyMuPDF.

После этого страницы передаются мультимодальной модели для извлечения текста.

### Изображения

Изображения JPG, JPEG и PNG передаются мультимодальной LLM напрямую.

### DOCX

DOCX обрабатывается локально.

Из документа извлекаются:

* текстовые параграфы;
* содержимое таблиц.

## 2. Извлечение параметров

После получения текста управление передаётся:

```text
retrieve_params.py
```

Модель получает:

* полный текст документа;
* список параметров, которые необходимо найти.

Например:

```text
Название месторождения
Глубина
Тип руды
```

Результат возвращается в JSON:

```json
{
  "Название месторождения": "...",
  "Глубина": "...",
  "Тип руды": "..."
}
```

## Запуск

Клонировать репозиторий:

```bash
git clone https://github.com/Norventorig/key_data_extractor.git
cd key_data_extractor
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать его.

Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Создать файл:

```text
.env
```

и указать API-ключ:

```text
api_key=YOUR_API_KEY
```

Запустить:

```bash
python main.py
```
